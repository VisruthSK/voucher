# Package index

## All functions

- [`add()`](https://voucher.visruth.com/reference/add.md) : Add a user
  to the vouched contributors list.
- [`check()`](https://voucher.visruth.com/reference/check.md) : Check a
  user's vouch status.
- [`denounce()`](https://voucher.visruth.com/reference/denounce.md) :
  Denounce a user by adding them to the VOUCHED file with a minus
  prefix.
- [`use_vouch()`](https://voucher.visruth.com/reference/use_vouch.md) :
  Initialize vouch in the current project
- [`vouch_gha()`](https://voucher.visruth.com/reference/vouch_gha.md) :
  Use 'vouch' GitHub Actions
